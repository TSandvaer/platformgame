## 🚀 Quick Links

- **Start the Game**: Open `index.html` in a web browser
- **Toggle Editor**: Press `Tab` key during gameplay
- **Save Scene**: Press `Ctrl+S` in development mode
- **Open Props Editor**: Click "Open Props Editor" in the dashboard
- **Open Lootables Editor**: Click "Open Lootables Editor" in the dashboard

## 🎮 Key Features

- **Integrated Level Editor**: Build and test levels in real-time
- **Multiple Platform Types**: Moving, spinning, damaging, and blocking platforms
- **Rich Prop System**: 50+ decorative and interactive props
- **Enemy AI**: Multiple enemy types with different behaviors
- **Scene System**: Multi-scene support with transitions
- **Inventory System**: Chest-based item storage
- **Combat System**: Melee combat with stamina management
- **Visual Effects**: Particles, damage indicators, and animations
